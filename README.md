# CVD 2D-Material Growth System — Interactive 3D Teardown

A laboratory-scale **chemical vapour deposition (CVD)** system rendered as an interactive exploded view in the browser. Every mesh, material, label and panel is generated by code — **no external 3D model files are loaded at any point**.

The rig is modelled on a horizontal tube furnace CVD system (APCVD / LPCVD capable) and contains **23 independently explorable parts**: quartz reaction tube, split three-zone furnace, gas cylinder bank, mass-flow controllers, mixing manifold, rotary-vane pump, scrubber, HMI cabinet, thermocouple, SCR power stage and more.

```
Three.js r186 · TypeScript 5.9 · HTML · CSS · Vite 7
```

---

## 1. Run it

### Option A — double-click (no Node, no server)

Open **`CVD-Visualizer.html`** in a modern browser.

That file is a fully self-contained build: three.js, CSS and all application code are inlined. It works from `file://`, a USB stick or an email attachment. It only needs a browser with **WebGL 2**.

> If you see the "Unable to start the 3D scene" message, jump to [Troubleshooting](#6-troubleshooting).

### Option B — development server

```bash
npm install
npm run dev            # http://localhost:5173
```

> Requires Node.js 20.19+ (see `.nvmrc`). If your Node is older, use the standalone file instead.

### Option C — production build

```bash
npm run build          # dist/       (static site: serve this folder)
npm run preview        # http://localhost:4173
```

### Regenerate the standalone file

```bash
npm run build:single   # writes dist-single/index.html and CVD-Visualizer.html
```

## 2. Controls

| Input | Action |
| --- | --- |
| Left-drag | Orbit the camera |
| Wheel | Zoom |
| Right-drag | Pan |
| **Single click** a part | Select it and explode / restore it (toggle "Click to Explode" in the toolbar to make clicks selection-only) |
| **Double click** a part | Smooth camera flight to an unobstructed view of that part |
| Hover a part | Emissive highlight + cursor tooltip |
| Component tree | Expand / collapse subsystems, search, explode, focus or hide individual parts |
| **+** on a subsystem | Explode / restore the whole subsystem |
| **Explode System** | Staggered, layered full teardown with automatic camera framing |
| View dock | ISO · Front · Gas Side · Vacuum Side · Top · Chamber · Reset |
| **Gas Flow** | Animated particles following the exact tubing routes |
| **Heating** | Hot-zone glow, element emission and warm point light |

Keyboard: `E` explode · `A` restore · `R` reset view · `F` focus selection · `Esc` clear selection / close guide · `1–6` preset views.

Debug query parameters: `?intro=0` skips the intro, `?explode=1` explodes on load.

## 3. What is implemented

- **100 % procedural geometry** — `ExtrudeGeometry` rounded housings, `LatheGeometry` hollow quartz tube (inner wall + outer wall + annular end faces), half-cylinder ceramic-fibre insulation, helical resistance windings, `TubeGeometry` gas lines, canvas-textured HMI / MFC screens and dial gauges.
- **Split furnace** — upper/lower shells and insulation halves separate along their real assembly direction, exposing the three-zone winding and the reaction tube.
- **Interruptible exploded animation** — every part owns its progress, target and delay; time-normalised `easeInOutCubic`; reversing mid-flight never fights over the transform.
- **Per-part highlighting** — the registry clones materials per part, so hover / selection / motion glow never bleeds into neighbouring parts. Emissive glow is amplified by UnrealBloom.
- **Screen-space callouts** — HTML labels projected from 3D anchors, with leader lines, collision-aware placement, camera-follow and part-follow behaviour.
- **Inspector** — part code, subsystem, state, specification table (size, material, temperature, flow / pressure, interface), operating principle and safety notes, all sourced from one data file.
- **Process explanation** — the default inspector view shows the five-step growth sequence; every button on the page is functional.
- **Gas-flow visualisation** — particles sample the same Catmull-Rom routes used to build the tubing, and fade out automatically during a teardown.
- **Responsive dark-tech UI** — glass panels, cyan accents, vignette/scanline overlays, HUD state, progress and FPS; side panels become drawers on narrow screens.

### Coordinate convention

- 1 unit = 100 mm; the bench top is `z = 0`.
- `+X` runs along the tube (inlet at −X, exhaust at +X).
- `+Y` is bench depth (gas panel and vacuum group at −Y, operator side at +Y).
- `+Z` is height. The camera's `up` is `(0, 0, 1)`; OrbitControls supports it natively.

All dimensions live in `equipmentConfig.ts`; all part names, parameters, explode offsets and label anchors live in `cvdParts.ts`. Changing one config value updates the model, interaction and UI together.

## 5. Performance notes

- ≈ 455 meshes, 150 k triangles and ≈ 600 draw calls including the shadow pass at 1600 × 1000.
- Shadows are limited to structural parts (146 casters); bolts, screens and emissive parts do not cast.
- Pixel ratio is capped at 1.5 and rendering pauses when the tab is hidden.
- **Adaptive quality**: if the measured frame rate stays below 24 fps after warm-up, the renderer lowers the pixel ratio, then disables bloom and shadows (`WEBGL 2.0 · ECO` / `SAFE` in the status bar).
- Geometries are shared; materials are cloned per part only where local highlighting requires it.
- If your browser falls back to software rendering (e.g. inside a VM), the scene still runs but at low frame rate — enable hardware acceleration for the full effect.

## 6. Troubleshooting

**"Unable to start the 3D scene"**
The browser does not provide WebGL 2. Enable hardware acceleration (Chrome → Settings → System), update the GPU driver, or try a current Chrome / Edge / Safari / Firefox build.

**I opened `index.html` and got a blank page or a CORS error**
The source `index.html` loads TypeScript modules through Vite and cannot be opened from the file system. Use `CVD-Visualizer.html` for direct opening, or run `npm run dev`.

**`npm run dev` says the port is in use**
Run `npm run dev -- --port 5180`, or open the URL printed in the terminal.

**The scene is very slow**
This is a software-rendered fallback (SwiftShader) in some virtual machines. Disable "Use software rendering" / enable GPU acceleration in the browser.

## 7. Disclaimer

Every dimension, temperature, flow and pressure value in this project is a **teaching schematic**. They are not the rated specification of any real instrument. Actual temperature limits, quartz-tube ratings, flange seals, hydrogen safety interlocks and exhaust treatment must follow the manufacturer's datasheet, the equipment manual and the laboratory safety rules.

The code is provided for teaching and demonstration and may be freely modified. The 3D model is a schematic reconstruction and contains no vendor CAD data.
